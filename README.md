## 2. Огляд функціональності та переваг Docker
[cite_start]Docker — це програмне забезпечення для автоматизації розгортання та управління додатками в середовищах, що підтримують контейнеризацію[cite: 363]. На відміну від традиційних віртуальних машин, Docker ізолює додатки на рівні процесів операційної системи. 

Основні переваги використання інструменту в інженерній практиці:
* **Консистентність середовища:** Повністю вирішує проблему розбіжності конфігурацій на машині розробника та продакшн-сервері.
* [cite_start]**Автоматизація рутини:** Налаштування оточення описується як код (IaC), що виключає людські помилки під час розгортання додатків[cite: 323, 324].
* **Ефективна ізоляція:** Контейнери працюють незалежно один від одного в межах однієї хост-системи, не перевантажуючи ресурси комп'ютера.
