## 1. Мета роботи
Навчитися розгортати та керувати Docker-контейнерами для веб-додатків. Опанувати процес написання конфігураційних інструкцій, збірки локальних образів, налаштування зв'язку між портами (Port Mapping) та перевірки працездатності контейнеризованого сервісу в ізольованій структурі.

## 2. Стек технологій та інструменти
* **Контейнеризація:** Docker Engine
* **Мова розробки та фреймворк:** Python / Flask
* **Контроль версій:** Git / GitHub

## 3. Компоненти директорії `prac_3devops`
Оскільки всі вихідні файли коду та інфраструктурних конфігурацій розгорнуті в окремих файлах всередині папки, цей документ містить опис структури без дублювання лістингів:
* `app.py` — вихідний код фонового веб-сервісу на Flask.
* `requirements.txt` — специфікація залежностей та версій пакетів проєкту.
* `Dockerfile` — покрокова інструкція для збірки Docker-образу.
