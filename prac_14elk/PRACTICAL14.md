## 1. Мета роботи
[cite_start]Налаштувати комплексну систему логування та аналізу даних за допомогою ELK Stack (Elasticsearch, Logstash, Kibana) для автоматичного збору та візуалізації логів із вебдодатка .

## 2. Реалізація інфраструктури
1. **Розгортання ELK:** Локально розгорнуто та запущено базові компоненти стеку. [cite_start]Elasticsearch працює на порту `9200` для індексації даних, а Kibana доступна на порту `5601` для візуалізації [cite: 906-914].
2. [cite_start]**Конфігурація Logstash:** Створено файл `logstash.conf`, який налаштовує читання даних із файлу логів вебдодатка (блок `input`) та їх передачу в базу Elasticsearch (блок `output`) [cite: 918-931].
3. **Генерація логів:** Написано вебдодаток на фреймворку Flask. [cite_start]Інтегровано модуль `logging`, який записує подію `Processing default request` у файл `logfile.log` при кожному зверненні до кореневого маршруту [cite: 936-946].

## 3. Аналіз даних
Після запуску Flask-додатка та генерації тестового трафіку, зібрані логи передаються через Logstash до Elasticsearch. [cite_start]У веб-інтерфейсі Kibana, використовуючи вкладку **Discover**, можна здійснювати пошук по логах, а також створювати інтерактивні дашборди для моніторингу помилок та кількості запитів [cite: 951-957].

## Висновок
[cite_start]Впровадження ELK Stack дозволяє здійснювати глибокий аналіз поведінки системи [cite: 958-959]. Централізоване логування є невід'ємною частиною DevOps-процесів, оскільки воно значно прискорює виявлення несправностей та допомагає оптимізувати продуктивність інфраструктури.
